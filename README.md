# WiFi Traffic Monitor for Android

A modern, privacy-first Android application designed to discover connected devices on the local Wi-Fi / LAN network and monitor real-time network traffic volume (download and upload speeds, cumulative bytes transferred, IP, MAC, and device metadata).

---

## 🔒 Privacy & Architecture Guarantees

This application strictly respects user privacy and complies with standard Android security policies:
- **Zero Content Sniffing**: No packet-content inspection, HTTPS interception, payload decoding, or deep-packet surveillance.
- **Zero Browsing History / DNS Interception**: The app does not collect website visits, query logs, passwords, or files.
- **Zero Cloud Communication**: No external servers, accounts, cloud sync, or third-party telemetry. All operations remain entirely within the local Wi-Fi subnet.

---

## ⚠️ Android Technical Reality & Limitations Explained

Understanding Android's networking security model is crucial for legitimate network monitoring tools:

1. **Switched LAN Isolation**:
   In modern Wi-Fi networks (and switched Ethernet), packets between a client (e.g. PC `192.168.1.10`) and the default gateway (`192.168.1.1`) are switched at layer 2. An Android phone cannot see other clients' unicast packets without ARP poisoning / MITM (which is illicit and harmful).
2. **Android TrafficStats Scope**:
   Android's native `android.net.TrafficStats` and `NetworkStatsManager` APIs only expose socket byte counters generated by **the local Android phone itself** and its installed apps (`UIDs`).
3. **MAC Address Protection**:
   Starting with Android 10 (API 29), access to `/proc/net/arp` is restricted by SELinux for non-root applications. MAC addresses are therefore randomized or protected unless provided by the router.

### How WiFi Traffic Monitor Solves This (The 3 Modes):

1. **Demo / Simulated LAN Mode (Default)**:
   Simulates multi-client Wi-Fi traffic (Samsung Galaxy, Workstation PC, Smart TV 4K, IoT Hub, MacBook) with realistic live jitter and byte counters for UI testing, live graphs, and sorting without requiring router setup.
2. **Local Device Mode (Android TrafficStats)**:
   Gathers true real-time download and upload counters from the Android device using `TrafficStats.getTotalRxBytes()` and `TrafficStats.getTotalTxBytes()`, while actively discovering other LAN devices and displaying their IP, hostname, status, and reachability.
3. **OpenWrt / Router Endpoint Mode**:
   Legitimately queries your local OpenWrt router or custom LAN gateway API to collect per-device interface RX/TX byte counters for all Wi-Fi clients.

## 🚀 How to Build and Install the APK

### Prerequisites:
- Java JDK 17 or higher
- Android SDK installed with platform-tools (`adb`)
- Gradle

### Exact Commands to Build the APK:

```bash
# Clone or navigate to the repository directory
cd /path/to/wifi-traffic-monitor

# Build the Debug APK
gradle :app:assembleDebug
```

The compiled APK will be generated at:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Exact Commands to Install the APK:

Enable **Developer Options** and **USB Debugging** on your Android phone, connect it via USB, and run:

```bash
# Check device is detected
adb devices

# Install APK to the connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 🧪 Testing with Two Phones and One PC on the Same Wi-Fi

1. **Connect Devices to Same Wi-Fi**:
   - Phone A (with WiFi Traffic Monitor installed): `192.168.1.50`
   - Phone B: `192.168.1.5`
   - PC: `192.168.1.10`
2. **Open the App**:
   - On first launch, the welcome screen presents the privacy guarantee. Tap **Start Monitoring**.
   - Switch to **Local Device** mode using the top pill bar.
   - Tap **Rescan LAN** (top-right refresh icon). The app performs parallel subnet discovery on `192.168.1.0/24`.
   - Both Phone B and the PC will appear in the device list with their hostnames, IPs, and active status.
3. **Generating Traffic**:
   - On Phone A: Start streaming a 4K video or run a speed test.
   - Notice the **"This Device"** card immediately reflects real-time download spikes (`↓ 4.5 MB/s`) and updates the live traffic sparkline.

## 🌐 Connecting to an OpenWrt Router

To see true per-device bandwidth for all clients (Phone B, PC, Smart TV), configure an endpoint on your OpenWrt router:

### 1. Simple OpenWrt Shell Script / CGI Endpoint
On your OpenWrt router (via SSH), create `/www/cgi-bin/traffic`:

```sh
#!/bin/sh
echo "Content-Type: application/json"
echo "Access-Control-Allow-Origin: *"
echo ""

echo "{"
echo "  \"router_name\": \"$(uci get system.@system[0].hostname 2>/dev/null || echo OpenWrt)\","
echo "  \"timestamp\": $(date +%s),"
echo "  \"clients\": ["

FIRST=1
# Read DHCP leases and wireless stations
for iface in $(iwinfo | grep -oE "wlan[0-9]+|ath[0-9]+"); do
  iwinfo "$iface" assoclist | awk '/^[0-9A-Fa-f:]+/ {print $1, $4, $5}' | while read mac rx tx; do
    ip=$(grep -i "$mac" /tmp/dhcp.leases | awk '{print $3}')
    host=$(grep -i "$mac" /tmp/dhcp.leases | awk '{print $4}')
    [ -z "$ip" ] && continue
    [ $FIRST -eq 0 ] && echo ","
    FIRST=0
    printf '    {"ip": "%s", "mac": "%s", "hostname": "%s", "rx_bytes": %s, "tx_bytes": %s}' \
      "$ip" "$mac" "${host:-Unknown}" "${rx:-0}" "${tx:-0}"
  done
done

echo ""
echo "  ]"
echo "}"
```

Make it executable:
```sh
chmod +x /www/cgi-bin/traffic
```

### 2. Connect in the Android App:
1. Tap the **Router Icon** in the top bar.
2. Enter the Endpoint URL: `http://192.168.1.1/cgi-bin/traffic`.
3. Tap **Save & Apply**, and select **Router API** mode.
4. The dashboard now shows real-time per-client upload and download speeds retrieved directly from the router!
